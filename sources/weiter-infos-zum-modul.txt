The submission must not contain any commented-out code passages.





Note on code comments: Code comments are helpful if they explain why a decision was made or why a calculation was carried out in the particular way or according to which source a calculation was implemented. In practice, however, code comments are often forgotten during code development. As a result, comments are often obsolete. My recommendation is therefore: as many comments as necessary, but as few as possible. In principle, the code should be written in such a way that it is self-explanatory.



Collaboration is allowed for the development of content. However, collaboration is limited to algorithmic questions and aspects of understanding.



The use of code sources (such as ChatGPT or StackOverflow etc.) must be specified.

Brightness, contrast, color mode, color saturation, sharpness, noise
